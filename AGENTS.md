Implement only the assigned task. One OpenCode agent, no subagents.
Use only the explicitly configured free OpenCode model. No paid fallback, paid APIs, credentials, external services, telemetry or external assets.
Game: plain HTML, CSS and JavaScript, Portuguese UI, keyboard and touch. No runtime dependencies. Separate deterministic game logic from DOM/rendering.
Allowed implementation paths: index.html, src/, tests/, e2e/. Do not edit infrastructure, workflows, package manifests, configuration, tasks or this file. Do not commit, push, open PRs or merge; the coordinator handles publication.
Unit tests: node:test. Browser tests: @playwright/test. Use the installed dependencies. Run npm test and npm run test:e2e. Report failures honestly.
